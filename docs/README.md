## Getting Started

### New Developers

If you're new to the project, follow these steps in order:

1. **[Development Setup](./DEVELOPMENT_SETUP.md)**
   - Install required software (Node.js, Git, Expo Go)
   - Clone repository and install dependencies
   - Set up your editor (VS Code recommended)
   - Run the app for the first time

2. **[Firebase Setup](./FIREBASE_SETUP.md)**
   - Create Firebase project
   - Enable authentication
   - Set up Firestore database
   - Configure security rules
   - Add credentials to app

3. **[Troubleshooting](./TROUBLESHOOTING.md)**
   - Refer here if you encounter any issues
   - Common problems and solutions
   - Where to get help

### Experienced Developers

Quick reference:

- **Installation:** `npm install`
- **Start dev server:** `npm start`
- **Run tests:** `npm test` (coming soon)
- **Lint code:** `npm run lint`
- **Format code:** `npm run format`

## Documentation Standards

When contributing to documentation:

- **Be clear and concise** - Avoid jargon, explain terms
- **Include examples** - Code samples help understanding
- **Test instructions** - Verify steps actually work
- **Keep updated** - Update when code changes
- **Use formatting** - Headers, lists, code blocks
- **Add screenshots** - For UI-related instructions
